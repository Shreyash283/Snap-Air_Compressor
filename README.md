# SNAP AIR COMPRESSOR — Marketing Website

Premium industrial marketing site built with React, Vite, Tailwind CSS, and GSAP ScrollTrigger.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Images

Place verified photography under `public/images/` using the paths documented in `public/images/README.md` and `src/data/products.js`. The UI uses `PlaceholderImage` so missing files show a branded placeholder until assets are added.

## Content

Copy and data live in `src/data/` and section components. Replace placeholder text with verified SNAP information before launch.
